# Public data and derived results

**Sahab** and **Amman–Airport** sample-level data are publicly available in [release/data](../release/data/) and the [updated reproducibility ZIP](../release/).

**Zagreb sample-level data are intentionally withheld.** Only its previously computed aggregate and split-level **results**, together with the analysis code, are supplied. To obtain original measurements, consult Frančišković-Bilinski et al. (2023), *Minerals* 13, 1481, DOI 10.3390/min13121481.

The Sahab analytic subset contains 48 admitted records (56 historical records, 54 resolved identities); Amman comprises 44 samples. The original frozen Amman V34 sample 8 fine-frequency value differs from another independent public reconstruction; see the source crosswalk before reusing either.
