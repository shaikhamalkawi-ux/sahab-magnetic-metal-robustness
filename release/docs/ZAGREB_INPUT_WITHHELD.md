# Zagreb site-level observations are not redistributed

The depositor requested that the 25-site Zagreb chemical and magnetic observation matrix be excluded from this project's GitHub release. The corrected public ZIP therefore contains **only derived Zagreb results and analysis methods**, not the source-level measurement table.

Original study: Frančišković-Bilinski et al. (2023), *Magnetic and geochemical properties of Zagreb city area soils*, *Minerals* 13(12), 1481. https://doi.org/10.3390/min13121481. Interested readers can consult Table 10 and Appendix A of that source and independently compile a matched analysis table.

The original V34 science and numerical outputs remain unchanged. However, complete Zagreb numerical replay **cannot** be performed from this reduced public archive alone; the included subset verifier checks Sahab/Amman inputs and outputs only.

A prior GitHub archive containing Zagreb observations was available and has been withdrawn from the current branch. Old commit history, forks, third-party clones and downloads may still hold those previously shared records. Current-branch removal does not erase those historical copies.
