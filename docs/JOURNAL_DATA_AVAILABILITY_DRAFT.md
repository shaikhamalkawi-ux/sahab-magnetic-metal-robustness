# Data Availability Statement — corrected for Zagreb non-redistribution

The source-reconciled 48-record Sahab analytic dataset, the 44-record Amman–Airport comparison dataset, historical source-reconciliation documentation, method code, frozen held-out split-level results, simulations, and SHA-256 manifests are publicly available at https://github.com/shaikhamalkawi-ux/sahab-magnetic-metal-robustness under the [updated release](https://github.com/shaikhamalkawi-ux/sahab-magnetic-metal-robustness/tree/main/release) (ZIP SHA-256: `e65d2485eea6cd87a557e0223dc72f044d7f6bd60efaad02b9c32627704d6a9d`).

The Zagreb analyses used 25 matched surface-location observations reported by Frančišković-Bilinski et al. (2023), *Minerals*, 13, 1481, DOI 10.3390/min13121481. Derived Zagreb results and analytic code are shared, but the numeric Zagreb source observations are **not redistributed** in this GitHub release. Readers may consult the original article and independently compile its source observations. Consequently, full three-study replay is not possible from the current public archive alone; the provided verifier repeats the Sahab and Amman portions. No new field measurements were collected for this reanalysis.

**This is a draft for the journal manuscript.** The previous Data Availability paragraph claiming Zagreb sample-level data were deposited on GitHub must be replaced, and the old commit/archive hash must be removed from all journal-facing materials.
