# Journal Data Availability Statement — draft for Sahab V34

The source-reconciled Sahab primary analysis dataset (48 samples), the Amman–Airport comparison dataset (44 samples), and the attributed Zagreb matched-site dataset (25 surface locations), together with the historical reconciliation ledger, analysis source code, held-out split-level results, simulations, manifests, and reproduction instructions, are publicly available in the GitHub repository [Sahab Magnetic–Metal Robustness](https://github.com/shaikhamalkawi-ux/sahab-magnetic-metal-robustness), within the [V34 reproducibility archive](https://github.com/shaikhamalkawi-ux/sahab-magnetic-metal-robustness/tree/main/release) (SHA-256: `4971969d21f1ba09741e2551eba952a21ef2bb1d4cd33334066e45cb7e73cb95`).

The Sahab primary subset comprises 48 reconstructed and admitted records from a 56-record historical magnetic survey; 54 cross-source identities were resolved, and the analytic data should not be interpreted as a new sampling campaign. The Amman–Airport and Zagreb studies are analyzed separately. The Zagreb numeric transcription is adapted, with attribution, from Frančišković-Bilinski et al. (2023) under CC BY 4.0. Reuse conditions and source-definition differences, including the separate Amman sample-8 reconstruction discrepancy, are documented in the repository.

The GitHub record has no DOI at present. The authors intend to consider Zenodo archiving only following journal acceptance. This research did not collect new field samples.
